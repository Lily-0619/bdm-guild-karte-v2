===========================================================
各ファイル説明
===========================================================

▽src フォルダ

・src/app.py
カルテ作成ツールのGUIアプリ本体（PySide6デスクトップアプリ）。
ボタンで以下を実行する：
  DBonk取得 / 一覧作成(analyze) / カルテPNG作成 /
  コメント元データ作成(comment_source) / AIコメント生成(comment_ai) /
  個人カルテへ(pv_detail_app起動) / 新しい収集を開始(session reset)
背景画像やアイコンは ui/assets を参照。session.py で収集セッションを扱う。

・src/paths.py
プロジェクトルート基準のパス定義（DATA_DIR, ANALYSIS_DIR, DB_PATH 等）と
ensure_dirs()。各スクリプトが共通で参照する。

・src/session.py
収集セッション管理。1回の連続したデータ収集を「開始日」で1つにまとめる。
夜またぎ・複数回実行に対応するため、data/.session.json に
セッション日付と収集済みギルドを保存する。
clear_session() で明示的に新しい収集を開始する。

・src/scraper.py
DBonkからギルドデータを取得する本体（Playwright）。
DBonkログイン → Asiaサーバー選択 → Guild Ranking検索 →
ギルド詳細 → members / summary / node_history 取得。
保存先：data/ギルド名/guild_ギルド名_日付.xlsx と data/bdm_guild.sqlite3
Excel保存後に save_guild_snapshot_to_sqlite() でSQLite保存。
session.record_guild() で収集セッションにも記録する。

・src/db.py
SQLite保存用の共通処理。DBの場所：data/bdm_guild.sqlite3
テーブル：
  guild_snapshots / member_snapshots / import_files /
  node_history_snapshots / guild_summary_snapshots
member_snapshots に将来のクラス名対応用の枠あり：
  class_name_raw / class_name_normalized / class_name_version
（クラス名抽出は今も未実装）

・src/import_excel_to_db.py
既存ExcelをSQLiteへ取り込む移行用スクリプト。
対象：data/**/guild_*.xlsx　取り込むシート：members / summary / node_history
使い方：python -m src.import_excel_to_db
import_files で取り込み済みを管理。file_pathは原則プロジェクトルートからの相対パス。

・src/analyze.py
ギルドExcelを読み込んでsummaryを作る分析処理（read-only / Excelベース）。
入力：data/ギルド名/guild_ギルド名_日付.xlsx
出力：analysis/summary_日付.xlsx
計算：平均CPM / 総CPM / 人数 / CPM帯人数 / 中央値 / 順位 /
　　　上位依存度 / 層の厚さ / 伸び傾向 / 自動コメント / source_file
収集セッション（session.py）に対応。SQLite読み込みには未移行（要検討）。

・src/make_card.py
カルテPNG生成処理。
入力：analysis/summary_日付.xlsx / ギルドExcel / template/karte.xlsx /
　　　analysis/comment_source/<日付>/ai_comments.json（あれば）
出力：output/cards/ギルド名/karte_ギルド名_日付.png
template のプレースホルダー置換・メンバー欄記入・グラフ作成・PNG出力。
AIコメント（normal/short/detail）をカルテに挿入する。

・src/cleanup_outputs.py
古いカルテPNG整理用スクリプト（PNGを消してもSQLiteは残る）。
python -m src.cleanup_outputs --dry-run
python -m src.cleanup_outputs --keep-latest-per-guild

・src/comment_source.py
AIコメントの「元データ」作成（AI作文の第1段）。
summary集計＋全体比較＋メンバー詳細を結合し、ギルドごとに
  ・Excelシート（目視用）
  ・Markdown（AI入力用）
を出力。analyze.py の日本語表現ヘルパーを再利用し、ルールベースの
自動コメント文言と整合させる。

・src/comment_ai.py
comment_source の材料からギルド別AIコメントをOllamaで生成（第2段）。
short / normal / detail の3種を生成し、
analysis/comment_source/<日付>/ai_comments.json（＋ギルド別md）に保存。
ギルド単位で独立生成し、1件失敗や停止で全体は止まらない。
進捗行 "[進捗] n/総数 ギルド名" を出力（GUIが解析してライブ表示）。

・src/autocomment_ollama.py
Ollama /api/chat 呼び出し共通処理。
generate_guild_comment / load_ai_config / call_ollama_chat / 整形ヘルパー。

・src/autocomment_prompt.py
AIコメント生成用のプロンプト・JSONスキーマ・systemテキスト。
COMMENT_SCHEMA / SYSTEM_PROMPT / build_*_material_text。

・src/autocomment_builder.py
AutoComment材料作成CLI（Excel/Markdown/SQLiteベース）。
現状どの実行系からも参照されておらず、comment_source+comment_ai の
現行系に置き換わった旧/実験系と思われる。整理（残す/消す）要判断。

・src/ollama_runtime.py
AI生成前にローカルOllamaサーバーが起動しているか確認し、
落ちていれば ollama serve を起動してAPI応答を待つ（urllibのみ・依存なし）。
未インストール等でも落ちずにメッセージを返してスキップさせる。

・src/pv_tracker.py
個人PVチャートのトラッキングエンジン（Bot・カルテ本体から独立）。
ギルドメンバーブックを読み、個人別PVブック（deta_PV/）を更新し、
手動補正・消失（×）履歴をSQLiteに保存する。

・src/pv_detail_app.py
個人PV詳細分析用のスタンドアロンGUI（Tkinter）。
「コメント作成 / PNG作成」ボタン、AIモデル選択ドロップダウン
（品質重視 gemma3:4b / 速度重視 lfm2.5）、ギルド別の進捗・ETAライブ表示。
make_card / comment_source / comment_ai をサブプロセスで呼ぶ。


▽bot フォルダ

・bot/main.py
Discord Bot起動本体。読み込むCog：
  karte / ogre_timer / admin / ai_talk / mini_game / voice
起動時にスラッシュコマンドを同期。.env に DISCORD_NOTIFY_USER_ID が
あれば起動時に指定ユーザーへDM通知。

・bot/bot_app.py
Bot起動・停止用のGUI（PySide6）。起動・停止・ログ表示。

・bot/config.py
Discord Bot用の設定定数（.env読み込み）。
  DISCORD_BOT_TOKEN / DISCORD_GUILD_ID / DISCORD_NOTIFY_USER_ID /
  OLLAMA_BASE_URL / OLLAMA_MODEL / OLLAMA_TIMEOUT_SECONDS / OLLAMA_NUM_CTX

・bot/cogs/karte.py
カルテPNGをDiscordへ投稿。 /guilds /karte /members /both
output/cards のギルド一覧表示・最新カルテ/メンバーPNG投稿・まとめ投稿。

・bot/cogs/ogre_timer.py
オーガタイマー。 /ogre
討伐後10分で再出現・5分バフ・開始ボタンから10分計測（ループなし）。
通知：オーガ没 / バフおわり / 3分前 / 2分前 / 1分前 / 30秒前 / 15秒前 / オーガ。

・bot/cogs/admin.py
Bot投稿ログ整理。 /clean_bot_logs
現在のチャンネルでBot自身の投稿だけ削除する。

・bot/cogs/ai_talk.py
MぼっとAIトーク。 /talk
mode: chat / translate、language: JP/EN/FR/ZH/RU/ES/AR。
通常chatは履歴保持、translateは履歴保存なし。ユーザーID＋チャンネルID
ごとに履歴管理。回数制限・クールダウンあり。軽量モデルのため精度は弱め。

・bot/cogs/mini_game.py
ギルドメンバー向けターン制モンスターバトルのミニゲーム。
コマンド（プレフィックス）：!hunt / !attack / !skill / !run / !status

・bot/cogs/voice.py
VC参加/退出。 /come（呼んだ人のVCにBotを参加）/ /bye（退出）。
読み上げBotがBotメッセージを読み上げない問題への対策。

・bot/services/ollama_service.py
Mぼっと会話用のOllama連携（/api/chat）。
config/m_persona.txt を読み込み、Mぼっとの人格・返答ルールをsystem promptに入れる。
設定：OLLAMA_BASE_URL / OLLAMA_MODEL / OLLAMA_TIMEOUT_SECONDS / OLLAMA_NUM_CTX

・bot/utils/file_finder.py
PNGファイル探索ユーティリティ。output/cards からギルド一覧・最新PNGを探す。
