# SQLite中心のデータ管理

ギルドカルテは `data/bdm_guild.sqlite3` を正式な保存・参照元として扱います。
既存DBを初めて開いたときは、過去の `member_snapshots` を削除せずに
`person_id` を自動付与します。

## 人物管理

- `persons`: 変更されない人物IDと現在の代表家門名
- `person_aliases`: 家門名・所属ギルドと人物IDの対応
- `member_snapshots.person_id`: CP、FCP、レベル、職業、所属の各履歴

同じ家門名・同じギルドは自動的に同じ人物として扱います。改名や移籍は
誤統合を避けるため自動統合せず、個人データ画面で確認する前提です。
手動統合後は過去スナップショットも同じ `person_id` に統一されます。

## 分析と画面

- 「一覧作成」はSQLiteの最新・前回スナップショットから直接計算します。
- メイン画面の「個人カルテへ」は別アプリを起動せず、SQLiteの個人一覧と
  履歴を同じデスクトップアプリ内で開きます。
- 既存Excelしかない環境では、SQLiteへの移行が終わるまで従来のExcel分析へ
  フォールバックします。

## ExcelとPNG

ExcelとPNGは正式データではなく任意の出力です。Discord Botは現在PNGを送るため、
PNG生成機能は互換性のため残しています。不要になった時点で別途削除できます。
